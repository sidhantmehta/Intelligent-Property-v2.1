Amenity weights

Higher weight = matters more to the total score. Scores update instantly as you type — no save or re-run needed for weight changes alone.

Reference points

Outcodes are scored on travel time to each of these. Weight edits update instantly; adding a point, renaming one, or changing its address needs "Save settings" plus an actual model run to fetch its travel times.
